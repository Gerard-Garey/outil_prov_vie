## 0. Objet, portée, statut

Ce document est le **projet** de la version `1.6` du dictionnaire de la base brute fictive (`docs/specifications/dictionnaire-base-v1.md`, version `1.5`, visée le 8 novembre 2026, M146). Il n'est pas le texte visé du dictionnaire : la transcription du projet visé dans `docs/specifications/dictionnaire-base-v1.md`, dans sa forme lisible par machine (`inst/extdata/dictionnaire/`) et dans `VERSION_DICTIONNAIRE_ATTENDUE` revient à la branche de code Bdr-b2 (`docs/feuille-de-route.md`, § 2).

Il spécifie, **sans les fermer**, les issues #60, #72, #81, #83, #90, #32 (point 2), et la forme de la valeur de chaque hypothèse `H` du § 9, dont #99 a besoin.

Pour chaque point, le projet donne :

1. la règle ;
2. le texte de la version `1.5` qu'il remplace (section et ligne) ;
3. le traitement déclaré de chaque défaut touché ;
4. l'effet attendu sur les dix couples de référence : **prévision** d'`actuary`, à remesurer par Bdr-b2 sur le code ; elle n'ouvre aucun visa de résultat ici.
